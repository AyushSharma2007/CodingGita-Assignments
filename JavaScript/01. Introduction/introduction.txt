Q14.
----> Static Website:

-Definition: Consists of fixed files (HTML, CSS, JavaScript) that are sent directly to the user's browser exactly as they are stored on the server. The content remains the same for every visitor unless manually edited by a developer.
-Example: A personal portfolio website or a small local business brochure site.

----> Dynamic Website:

-Definition: Content changes dynamically based on user interaction, time of day, or data retrieved from a database using server-side languages (like Node.js, Python, or PHP).
-Example: Amazon, YouTube, or a social media news feed (where content updates uniquely for every user).

Q15 Client-Side Execution: JavaScript runs directly inside the user's web browser without needing to send every single request back to the server. This makes interactions lightning-fast.

DOM (Document Object Model) Manipulation: JavaScript can dynamically find, modify, add, or delete HTML elements and CSS styles on the fly, allowing web pages to respond instantly to user actions (like clicks, hovers, or form inputs).

Q17. Difference: Internal JavaScript is embedded directly inside the HTML document within <script> ... </script> tags. External JavaScript is written in a separate file ending with a .js extension and linked into the HTML document using the src attribute (e.g., <script src="script.js"></script>).
--> Two Advantages of External JavaScript:
-Code Reusability: A single .js file can be linked across multiple HTML pages, avoiding code duplication.
-Cleaner Code and Maintainability: Separates behavior (JavaScript) from structure (HTML), making the code easier to read, debug, and maintain.

Q18. Frontend (The Dining Area & Waitstaff): This is what the customer directly sees and interacts with. It includes the dining room's ambiance, the menu card, and the waiters who take your order and present the final food. In web development, this translates to the user interface, buttons, layout, and animations.
Backend (The Kitchen & Chefs): This is the hidden infrastructure working behind the scenes. The kitchen receives the order, processes ingredients stored in the pantry (database), cooks the meal according to recipes (server logic), and sends it back out. The customer never sees the kitchen operations, but the restaurant cannot function without it.

Q19. -Ubiquity & Versatility: JavaScript is the undisputed language of the web and can now be used for frontend, backend, mobile apps, desktop software, and even IoT.
-Immediate Feedback & Easy Setup: You don't need complex compilers or installations to start; a simple text editor and any web browser are enough to see your code run instantly.
-Massive Job Market & Community: It is one of the most in-demand programming languages globally, backed by a massive community and countless learning resources.
-Gateway to Advanced Concepts: Learning JavaScript helps beginners grasp core programming concepts (like variables, loops, functions, and asynchronous programming) that easily transfer to other languages.
